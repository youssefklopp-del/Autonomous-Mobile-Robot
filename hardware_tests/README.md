# Hardware tests

Coordinated by the relevant mechanical, electrical, control, and vision owners.

Store bench-test procedures and curated measured results here. For each test record date, operator, hardware and firmware revision, setup, expected behavior, measured outcome, pass/fail criteria, and issues.

Begin with power and wiring checks, then sensors, encoders, motor direction, low-speed feedback control, and integrated behavior. Use appropriate current limits and an accessible emergency stop.

Status: scaffold; no hardware validation has been performed by this repository setup.
