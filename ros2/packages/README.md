# ROS2 packages

Infrastructure: Basyouni. Navigation: Makarios.

Place ROS2 package source directories here. Each package should declare its dependencies, build type, license decision, node interfaces, configuration, and relevant tests. Keep generated build, install and log directories out of Git.

Suggested future boundaries: robot description, Gazebo integration, bring-up, navigation, and interfaces. These are planning suggestions; no executable packages exist yet.
